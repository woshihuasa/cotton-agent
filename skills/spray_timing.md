# 打药适宜性判断

## 编排步骤

1. 调用 `get_weather` 获取目标地区天气预报
2. 检查风力 ≥4 级 → 不宜（药液飘移）
3. 检查当天或次日有降雨 → 不宜（药液被冲刷）
4. 检查日均气温 <15℃ 或 >32℃ → 不宜（药效差或药害风险）
5. 全部通过 → 适合

## 边界

- 只判断**天气条件**，不涉及农药选择、浓度、安全间隔期
- 超出范围的问题（如"用什么药治红蜘蛛"）走知识库检索
